# TotalEnergies Pro — Home Assistant integration

**Status: scaffolding — not usable yet.** Unofficial, not affiliated with TotalEnergies.

Brings TotalEnergies **business** customer data (pro.totalenergies.fr) into Home Assistant, read-only:
invoices, billed electricity and gas consumption per time class, **costs and effective prices per kWh**
for the Energy dashboard, and contract facts (tariff option, subscribed power). Designed to complement
the distributor integrations that measure the quantities (Enedis, GRDF). A refused password is never
retried. See `docs/`. License: MIT.

---

*FR* — Intégration non officielle pour les clients professionnels de TotalEnergies : factures,
consommations facturées par poste, coûts et prix effectif au kWh pour le tableau de bord Énergie,
informations de contrat. Lecture seule ; un mot de passe refusé n'est jamais réessayé.
